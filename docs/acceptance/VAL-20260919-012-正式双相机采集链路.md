## 新增与增强测试

新增12项Session集成场景与1项Demo测试：

| 场景 | 验证内容 |
|---|---|
| normal | 两个独立Camera宿主持续采集；正式描述、逐字节验证、释放及重复释放拒绝 |
| replay | 三个PGM文件按顺序跨任务读取，经过同一宿主/帧通路 |
| timeout | 缺帧产生TimedOut，不产生成功图像 |
| cancel | Cancelled立即可见，但OS退出前写租约仍保留，拒绝接纳下一任务 |
| crash | 工作进程退出后失败结算，租约最终为0 |
| disconnect | 采集失败，不伪造成功描述 |
| duplicate / out_of_order | 旧描述与当前任务不匹配，被宿主拒绝 |
| isolation | 相机A缺帧失败；相机B共完成6帧，其中失败发生后仍继续采集 |
| restart | 正常停止后新epoch、新池；旧描述不能读取 |
| recovery | 第3次采集崩溃，第4次为显式新宿主成功采集；peer完成4帧，最终leases=0 |
| backpressure | 两个未释放消费者占满池，拒绝第三次接纳；释放后恢复 |
| demo | 两台相机各三帧的可运行应用入口，自动清理退出 |
