## 变更与边界

- 海康插件仍隔离在 `plugins/hik-camera`，真实 MVS 适配器编译通过。
  本轮将 fake 后端与测试入口拆开，测试实际触发、取帧、共享内存读取及三种像素格式，
  并通过真实 worker-host 检查崩溃/卡死/坏帧/断开/无帧不阻止另一个宿主继续采集。
- S7 首版 hex 读写原型已替换为兼容 DeviceSession 的 Communication 插件，
  使用 session/sequence/result token 和业务 ACK；补齐 manifest。
  Snap7 仅在插件中动态链接，默认关闭，公共 ABI、核心和 UI 不增加厂商 SDK 依赖。
- S7/Modbus 增加有界 JSON、重复 key 拒绝、数字地址、配置范围与重叠校验；
  序号在写入前占用，IO 或回执失败后实例失效，不重放状态不明的动作。
  未读取报告时返回 Busy，输出缓冲不足保留报告，停止后拒绝新命令。
- 配置与部署说明：[T22-T23-deployment](../tasks/T22-T23-deployment.md)。
  手工配置的真实设备访问和现场联调不在自动化测试中执行。
