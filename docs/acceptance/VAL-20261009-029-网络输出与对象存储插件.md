# VAL-20261009-029：网络输出与对象存储插件

日期：2026-10-09，Windows x64 / MSVC v143 / Release。
关联 ADR-014 与插件扩展实施计划。仅验收第一批软件范围。

## 实现

- 新增 Webhook：libcurl、有界 POST、Bearer 环境变量、幂等键、严格业务回执。
- 新增可选 MQTT：Paho C 异步客户端、本机 broker、PUBACK 与业务回执分别核验。
- 新增 S3 ObjectStorage：提交结果关联原图、目的地绑定、签名上传、回读哈希、
  Available 状态、三次尝试上限、与存储工具共享上传锁。
- 公共加载器/worker-host 接入 ObjectStorage；持久 agent 增加受限白名单。
  Webhook/MQTT 未显式声明非物理幂等策略时拒绝重放。
- 保留既有进程隔离、预算、状态模型；没有扩大超时或取消断言。
- Paho 上游原始许可/版权说明纳入 dependencies/licenses/paho 并部署；
  源与部署目录五个文件逐字节一致，框架自身许可证仍待定。

## 测试覆盖

Webhook 20 项：14 个直接契约场景、5 个独立宿主场景、1 个持久 agent 场景。
覆盖正常/重复、非法 URL/令牌、拒绝、重定向、空/畸形/重复键/超大/错身份回执、
无业务确认、离线、慢响应、停止与健康输出并行。

MQTT 21 项：15 个直接契约场景、5 个宿主场景、1 个持久 agent 场景。
覆盖连接/订阅拒绝、仅 PUBACK、缺 PUBACK、错身份/attempt、
畸形/超大/retained 回执、断连、离线、静默与健康输出并行。
使用受控本机协议对端，不是正式 broker 互操作验收。

S3 13 项：8 个直接契约场景、4 个宿主场景、1 个持久 agent 场景。
覆盖成功/重复、拒绝、回读损坏、锁冲突、未提交结果、无归档、重试终止、
慢服务与健康输出并行。
另启动真实本地 RustFS，验证既有工具及新插件直接/宿主 PUT/GET 路径。
