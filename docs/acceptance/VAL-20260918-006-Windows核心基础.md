## 覆盖的行为

- 强类型 ID 不可互换；uint64 最大值及 2^53 以上值无精度损失；错误数值/格式拒绝。
- 必需/可选检查、身份七维核对、缺项保持未完成、失败零缺陷仍 Unknown、保留局部 NG、超时后迟到成功拒绝。
- 一次终结、重复报告、计数去重、计数容量满不丢旧身份；四类规则的空输入/缺分类/单位/端点/NaN。
- 队列条数与字节成本双限制、拒绝不移动输入、关闭排空、两生产者与一消费者并发记账。
- 组合资源不足零扣减；预留精确到期；重复提交/释放；移动式票据；已提交超时不释放；期限加法溢出拒绝。
- JSON 重复键、未知字段、版本、过大/过深、身份和质量伪造；manifest 路径逃逸、错误版本/实例上限；参数范围/类型/运行中修改限制。
- CLI 五种情景及非法命令；四项反向依赖检查；GUI 自动点击全部五按钮并核对状态、质量、计数与票据释放。

GUI 截图为 `out/build/windows-gui/tests/workstation-smoke.png`，已人工查看工具图像，确认中文、按钮、结果区和底部限制说明可读。只验证当前尺寸，不声称已完成多屏/DPI/无障碍验收。

## 失败及修复

首次新增基础测试因 Windows 中文绝对路径的窄字符串文件读取失败，14/15 场景通过；记录保留在 `out/validation/2026-09-18T16-08-37-673Z/`。改用 C++20 UTF-8 filesystem path 后通过，随后消除弃用 API 警告。

离屏截图最初没有字体，自动按钮行为通过但文字显示方框。测试模式加载本机系统微软雅黑字体后截图可读；未复制/分发系统字体文件。正常窗口继续使用系统字体发现。

结果交付先完成快照复制再标记已交付，避免复制失败丢失唯一终态通知；演示事件 ID 加入本进程新建运行身份，避免多次启动复用 event_id。
