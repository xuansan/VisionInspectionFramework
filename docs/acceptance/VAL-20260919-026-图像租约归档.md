# VAL-20260919-026：正式图像租约到本地归档

关联任务：[T24图像租约归档](../tasks/T24-图像租约归档.md)。本批延续用户批准的T24/T27联接，不开启Production。

## 实现与边界

- 新增独立vision-frame-archive进程；有界stdin配置、受工位Job管理，不在主控执行SQL或图像文件写入。
- 采集描述符经BufferBroker移交，归档进程复制像素后释放共享读锁，再Flush暂存并记录SQLite。
- 只有正常进程退出、期限内身份回执确认后才归还租约给算法；异常则隔离并等待退出后释放。
- 单工件、双相机、原工件期限；图像归档是算法之前的顺序步骤，尚非高吞吐并行归档服务。
- schema v4新增archived_frames，保存通道、run/inspection、描述符、有效配方快照及hash。
- 原始像素本地归档与远端Available不同；本批不声称RustFS自动上传或分割掩码已接通。
