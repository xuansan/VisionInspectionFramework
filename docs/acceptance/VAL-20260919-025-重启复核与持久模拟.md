## 架构与计划逐项核对

| 约定 | 本次核对结论 | 边界 |
|---|---|---|
| 主控负责调度，外部IO进独立宿主 | SQLite/文件输出通过Dispatcher和插件宿主运行；清算由独立QProcess执行 | 完整常驻生产调度未完成 |
| 持久确认后才允许物理回报 | DemoRunner等待take_committed；超时为Unknown且不发送模拟PLC结果 | 模拟PLC，不代表真实剔除机构验收 |
| 输出相互隔离且容量有界 | 独立输出lane；清算stdin64KiB、输出8KiB、总期限20秒 | 系统级断电、驱动故障不能由进程隔离保证 |
| 不把待处理为零当作成功 | 已以acknowledged/unconfirmed汇总确认，增加Failed/Expired/混合终态反例 | 历史失败会使同一输出汇总仍不成功，后续须有人工处置流程 |
| 存储在专用线程执行 | SQLite连接由IO线程建立、复用并关闭 | 时限未放宽；不能因此宣称任何负载下都不超时 |
| Production准入诚实 | ProductionController仍拒绝非Demo启动，清算报告production_ready=false | T22～T27不能整体关闭 |
| 文档状态一致 | 修正T24子表仍写未开始以及Volatile描述过时的问题 | 父任务完成仍为21/32，不代表工作量百分比 |
