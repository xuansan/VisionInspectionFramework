# 数据库依赖构建记录

固定验证基线：MariaDB Connector/C 3.4.5、MySQL 8.4.4、PostgreSQL 17.4。
这是一份本机可复现构建记录，不宣称使用最新版本或完成发布许可审计。
官方来源和归档哈希见 `dependencies/artifacts.lock.json`。

## Connector/C

源码：`开发环境/源码/mariadb-connector-c-3.4.5`，
commit `c61bdb5ac1cd1b41210dd57bb14fa377e555ce0c`，应用本仓库的最小构建补丁
`dependencies/patches/mariadb-3.4.5-windows-openssl.patch`。
安装：`开发环境/SDK/mariadb`。构建：`out/dependencies/mariadb-openssl`。

先从 PostgreSQL SDK 的 `include/openssl` 复制到
`开发环境/SDK/mariadb/include/openssl`，避免把 PostgreSQL 的其他头文件
加入搜索路径，造成 bundled zlib 的 `zconf.h` 版本混用。
OpenSSL 头文件、import lib、DLL 均取自同一 PostgreSQL 归档，DLL 文件版本 3.0.16。

在仓库根目录运行，`cmake` 应是 VS2022 提供的版本：

```powershell
$dbRoot = (Get-Location).Path
git -C 开发环境/源码/mariadb-connector-c-3.4.5 apply "$dbRoot/dependencies/patches/mariadb-3.4.5-windows-openssl.patch"
cmake -S 开发环境/源码/mariadb-connector-c-3.4.5 -B out/dependencies/mariadb-openssl `
  -G "Visual Studio 17 2022" -A x64 `
  "-DCMAKE_INSTALL_PREFIX=$dbRoot/开发环境/SDK/mariadb" `
  -DWITH_UNIT_TESTS=OFF -DWITH_CURL=OFF -DWITH_SSL=OPENSSL `
  -DWITH_ICONV=OFF -DWITH_MSI=OFF -DCLIENT_PLUGIN_PARSEC=OFF `
  -DCLIENT_PLUGIN_CACHING_SHA2_PASSWORD=STATIC -DCLIENT_PLUGIN_SHA256_PASSWORD=STATIC `
  -DINSTALL_LIBDIR=lib -DCMAKE_C_FLAGS=/utf-8 `
  "-DOPENSSL_ROOT_DIR=$dbRoot/开发环境/SDK/PostgreSQL/pgsql" `
  "-DOPENSSL_INCLUDE_DIR=$dbRoot/开发环境/SDK/mariadb/include" `
  "-DOPENSSL_SSL_LIBRARY=$dbRoot/开发环境/SDK/PostgreSQL/pgsql/lib/libssl.lib" `
  "-DOPENSSL_CRYPTO_LIBRARY=$dbRoot/开发环境/SDK/PostgreSQL/pgsql/lib/libcrypto.lib"
cmake --build out/dependencies/mariadb-openssl --config Release --target install
```

上游 DLL 内部使用 /MT，项目插件使用 /MD；调用使用客户端自身提供的释放函数，
不跨库释放其分配的内存。客户端动态链接。
只部署 libmariadb.dll 和必要 OpenSSL DLL；不部署未启用的认证扩展。
`caching_sha2_password` 支持本次 MySQL 8.4 测试账号，不依赖动态认证插件下载。
SChannel 初次构建的目录保留诊断证据，但不是最终数据库插件的 TLS 基线。
补丁同时强制校验本地连接的证书主机名，避免上游默认跳过本地地址校验。
只在干净的固定提交上应用一次；已应用的源码不要重复执行 git apply。

## libpq 与测试服务

PostgreSQL EDB 二进制归档解压到 `SDK/PostgreSQL/pgsql`：
链接 `lib/libpq.lib`，部署 bin 下 libpq、OpenSSL、
libintl、libiconv、libwinpthread DLL。未部署 pgAdmin 或 PostgreSQL 服务端。

MySQL 便携归档位于 `SDK/MySQL/mysql-8.4.4-winx64`，仅用于测试。
测试脚本会复制必要的 bin/share/lib 到 ASCII 临时目录，避免中文路径编码问题，
临时数据不属于 SDK。未安装系统服务、未修改 PATH。
