# HTTP 输出 v1

本插件是独立 ResultOutput 宿主中的只读后端，不包含前端，不接受设备控制。
REST 读取 SQLite 已提交结果；SSE 展示本宿主收到的事件，两者可能有时间差。
HTTP 的 BusinessAcked 表示已进入有界实时窗口，不表示任何远端用户已收到，更不表示数据库已持久确认。

参数为 `root`、`port`、`token_env`。令牌通过指定环境变量提供，长度32～128；
所有请求都需要 `Authorization: Bearer <token>`。插件只监听127.0.0.1。
远端部署须配置TLS反向代理并转发鉴权，不应把本地明文监听直接暴露到公网。
GET以外的方法拒绝；没有写入、生产启动或PLC动作接口。

接口定义见 `http-output.openapi.json`。详情路由中的ID为event_id。
分页cursor为SQLite插入游标，字符串形式避免JavaScript精度丢失；limit为1～200。
服务存活、存储可读、最近事件新鲜度分别报告；production_ready当前始终false。

SSE采用有限批次：最多64条，每条不超过32KiB，返回后关闭并建议一秒后重连。
事件ID是`宿主随机代号/单调序号`，跨重启或超出窗口返回409；客户端应重新查询历史再建立实时连接。
这不是持久消息队列，也不保证客户端断线期间的全量事件投递。
浏览器原生EventSource不能设置Bearer头，前端可用fetch流读取或通过鉴权代理接入。

图像Pending返回409，Missing/Deleted返回404，只有Available允许申请访问。
访问URL仍要求Bearer，expires仅是请求有效时间检查，并非匿名预签名链接或不可篡改授权票据。
内容当前来自经过大小及SHA256校验的本地暂存副本，RustFS上传工具成功PUT/GET校验后才标记Available。
本地副本缺失时返回503，不伪装成功；直接远程对象读取/签名URL留在存储恢复闭环中完成。

边界：4个HTTP工作线程、最多8个排队连接；读写空闲超时300ms；
同宿主鉴权后每秒最多64请求，超额429；请求体1KiB、URI2KiB、头总量8KiB。
存储只读连接忙等待30ms，SQL执行进度预算100ms。操作系统文件IO仍可能阻塞，
最终故障隔离依赖独立宿主及现有监护机制。不能把空闲超时理解为整条连接绝对总时限。
