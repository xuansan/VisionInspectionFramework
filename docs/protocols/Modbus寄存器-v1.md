# Modbus TCP寄存器 v1（软件协议验收，现场待确认）

独立Communication DLL，数字IPv4、显式port/unit/write_base/read_base。
FC16写24寄存器，FC3读25寄存器，大端字序；两段不能重叠。
单次报文绝对期限50ms，验证MBAP事务/协议/unit/长度、功能码和写确认地址/数量。
异常、断线、旧会话/命令/结果ACK都失败，不自动重发物理动作。

| 写偏移 | 内容 |
|---|---|
| 0～7 | session_id的SHA256前128位 |
| 8～11 | command_sequence uint64 |
| 12 | Ready请求，0/1 |
| 13～20 | result_id的SHA256前128位；无结果为0 |
| 21 | 是否有结果 |
| 22 | PLC看门狗有效期，固定200ms |
| 23 | 质量：0未知、1OK、2NG |

| 读偏移 | 内容 |
|---|---|
| 0～7 | PLC当前session token回显 |
| 8～11 | 实际处理命令序号 |
| 12 | bit0 Ready、bit1实际到位、bit2实际安全条件；其他位禁止 |
| 13～16 | 实际到位沿计数uint64 |
| 17～24 | 已执行业务结果token；无本次结果必须0 |

PLC端必须实现会话接管核对、结果去重、先执行业务再ACK、看门狗过期清Ready。
Modbus寄存器写确认不等于机械动作成功，宿主等待读回业务token。
主机死亡无法继续写撤销指令，安全行为依赖PLC端看门狗，不可由TCP客户端替代。
本机测试使用真实TCP假PLC寄存器端，覆盖正常/分包/断线/超时/旧ACK/错误事务。
未指定现场PLC型号及梯形图、未连接机械执行器；不得据此启用Production。
