# 模拟设备v1（T13）

仅Demo，不实现真实Modbus寄存器或安全PLC。JSON中所有计数为uint64十进制字符串，
bool为单值；不存在字节序/字序转换。真实寄存器布局及安全联锁仍属T23。

DeviceTask/DeviceFinished是有认证和关联的原子快照交换。
请求包含session_id、command_sequence、ready、arrival、position、safety_ok、
result_id（null或事件ID）、quality（Unknown/OK/NG）。无result时quality必须Unknown。
应答回显session/command，包含ready、arrival_sequence、position、safety_ok、
ack_id（null或结果ID）。宿主/控制端均校验，旧会话不可接管。

模拟插件以到位上升沿增加arrival_sequence，持续高不会再触发；下降后再武装。
Ready租约200ms，只有来自实际应用循环的交换可更新；急停/位置失效立即撤销。
控制适配器快照也有200ms时效，过期/进程故障/停止必须显示未就绪。
这是软件演示联锁，不承担安全系统职责。

结果每个ID只发送一次。命令包含完整字段后一次提交，不拆开有效标志和结果值。
暂停撤销新Ready但允许原工件结果ACK；旧ACK不能匹配当前result_id。
ACK丢失、通道中断、截止超时记Unknown并撤销Ready，不自动重发物理动作。
有界性：单个在途交换、一个待交付结果、一个报告槽；已使用事件ID最多4096。
会话重新建立需要新worker epoch，旧会话结果不恢复。
