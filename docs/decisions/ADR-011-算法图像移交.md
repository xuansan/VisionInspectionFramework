# ADR-011：基础算法的共享图像移交

2026-09-19，T11已由VAL-013验收；后续T12～T15继续全量回归。

新增 `InspectTask`，包含slot_count、slot_bytes、read_frame、budget_ns；
应答复用严格TaskFinished。握手声明inspect-v1，旧端不应默许新消息。
frame的run/worker/epoch必须和认证消息一致，参数由插件manifest校验。

BufferBroker把一个有效Published读租约原子替换为算法worker/epoch的新租约。
旧租约即刻失效；此操作仅在旧读者已停止访问时调用。不存在提前free再重新借用窗口。
采集适配层保留池所有权；算法适配层借用它，必须先析构算法适配层。
算法返回时必须已结束所有图像访问；失败/超时/取消不能证明停止时隔离该租约，
只在对应epoch的OS退出后清算。迟到结果不能改写终态，重启不自动重放。

基础算法对Mono8/RGB8/BGR8有效像素通道求整数均值，忽略行padding，
用闭区间[min,max]判定OK/NG；它是测试性亮度检查，不声称缺陷识别能力。
共享映射只读、有限等待；参数/图像格式错误为Failed/Unknown。

验收：不同像素和阈值导致可预测OK/NG，padding不参与均值；坏身份/旧租约拒绝；
取消、超时、崩溃不产生OK；故障算法不阻塞健康链路；退出后无遗留租约。
