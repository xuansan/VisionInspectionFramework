# T19实现细则

采用固定CPU契约：输入NCHW float32，预测[1,4+C+K,N]，
原型[1,K,Hm,Wm]，两个显式输出名。类别为概率，无objectness。
后处理保持候选索引，类别内NMS之后才计算入选实例掩码。
系数乘原型后sigmoid，最近邻映射回原图像素中心，框外为0，阈值0.5。

限制：最多64实例、32原型通道、原型最大256×256，
原图每个掩码最多1MiB、全部掩码最多16MiB；预测张量最多2M float。
错误大小在分配掩码前拒绝。取消按行检查。

掩码不进入JSON。采用本批次本地有界文件缓冲（非T24持久对象存储）：
插件在专属目录写入内容hash命名的二值掩码文件，
结果仅携带hash、尺寸、字节数与实例序号。目录容量限定64MiB，
不自动删除仍可能被结果引用的文件；容量不足明确失败。
使用者读取时校验hash及长度；不可把该引用误标为持久保存。
专属目录由试运行/回放会话持有，宿主停止并读取结果后释放临时目录；
崩溃遗留目录由后续诊断/清理流程处理，不能从插件任意删除其他目录。
