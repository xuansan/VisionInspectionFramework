# T07：任务调度、期限与取消

日期：2026-09-19。前置 T04/T05/T06；设计依据 ADR-007。用户已批准继续多个阶段。

状态：运行基础范围已完成，假时钟和真实任务子进程集成通过，见[VAL-009](../acceptance/VAL-20260919-009-监护与调度验收.md)。图像租约和完整领域协调不在本任务完成声明内。

## 实施内容

- 纯 C++ TaskScheduler 按容量保留任务，接纳前组合预留并提交资源，失败不部分扣减。
- 本次运行生成单调 task-N，所有终态使用完整 correlation；不保留无限历史 ID 集合。
- 同 worker 一次只执行一个任务，旧 epoch 尚未停止也阻止派发；不同 worker 可并行。
- 总期限含排队时间。队列中超时不派发、立即归还本地预算；运行中超时/取消只形成一次终态并产生取消请求，不提前释放执行资源。
- 接收到完整匹配的 TaskFinished 视为该任务停止；迟到成功不改原终态。IPC 已超时而丢弃迟到回复时，靠 Supervisor 终止进程及 OS 退出证据回收。
- worker_exited 只能由可信 OS 退出事实调用，不能由 socket 断线调用。只回收对应 worker/epoch。
- 不自动重发或重试，避免重复物理动作；安全重试以后需领域授权的新 attempt。
- 未消费终态占用容量，反压上游，不能靠丢弃终态保持接纳。

## 验收

假时钟验证容量、排队、重复/旧身份、超时后迟到、取消、实际停止前资源保留。真实子进程接通 ProcessHost 的 SubmitTask / Cancel / TaskFinished，测试正常、迟到、忽略取消直到进程被杀、取消完成，以及累计请求预算触发多次会话轮换。

本批没有图像池、真实算法、InspectionCoordinator；对应 T08/T11/T12。调度器的销毁顺序必须晚于工作进程停止，资源预算必须晚于调度器销毁；应用集成遵循该生命周期，不靠析构自动停止远端执行。
