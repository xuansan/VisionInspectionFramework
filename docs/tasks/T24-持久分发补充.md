# T24 持久分发补充实施

沿用ADR-012，不改变父任务验收条件。数据库结果与意图已经同事务提交；
继续增加独立交付租约表，记录到期时间、尝试号、宿主会话令牌。
未获得租约不得发送；重启后只能重试非物理输出；旧令牌和旧尝试ACK不得修改新尝试。
每输出最多三次尝试，总TTL60秒，单次租约三秒。达到期限或次数上限形成明确终态。
数据库失败不得伪造已提交/已确认；原检测质量保持不变。

软件测试需覆盖：提交后重开数据库、发送前重启、成功但ACK未落盘、旧ACK、
TTL到期、数据库锁/容量耗尽、损坏及独立输出故障。
本补充不等于真实PLC控制权或整机断电验证，也不自动开启Production。
