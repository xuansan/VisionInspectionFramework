# T21回放资产与副作用边界

沿用T20的TrialSession，公开为ReplayService；只构造固定文件相机和算法宿主，
不构造Station/ProductionController、PLC、Dispatcher或生产计数器。
三种算法共用此路径；新运行有独立run/epoch，结果mode固定Replay。

资产包包含模型、有效参数（含标签、ROI、阈值、预处理契约）和输入PNM。
创建时读取同一份模型字节校验hash后复制；图像严格解析并计算文件及像素hash。
manifest按规范JSON计算snapshot_hash，目录以该hash命名。
所有写入只允许新建；已存在包必须完整校验，不覆盖修补旧包。
重新运行需要显式manifest路径和预期snapshot_hash；校验缺文件、内容修改、
尺寸、模型和像素hash，拒绝未知字段和生产输出参数。

这是内容校验的不可变资产API，不是操作系统禁止管理员修改文件；
外部修改必须被检测，不得静默重新计算hash后接受。
模型宿主再次校验实际加载字节，文件相机再次校验实际送入共享内存的像素。
快照内相对文件名固定，不从manifest接受任意路径。

测试：重复回放的分类/框/分数保持一致而run不同；篡改/缺资产拒绝；
原始文件及首次结果不被修改；请求物理输出字段拒绝；取消后进程退出。
尚不具备T24数据库历史查询和RustFS下载集成，不修改原生产结果。
