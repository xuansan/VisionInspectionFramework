# OpenCV 算法插件实施计划

2026-10-10，用户已批准执行。HALCON 另行实施，Windows 优先。

1. 核实现有 Algorithm ABI、共享图像租约、结果证据、SDK 版本与构建边界。
2. 新增 plugins/algorithm/opencv，可选构建，OpenCV 依赖限制在插件内部。
3. 实现阈值/形态学、连通域统计/筛选、像素尺寸、固定尺度角度模板定位。
4. 验证配置、ROI/格式/stride、资源上限，复用 worker-host 隔离与期限。
5. 算法确定性测试、实际 DLL/共享图像、双相机完整流程、取消/故障隔离。
6. 更新配置、来源/许可记录、进度、验收文档；完整 windows-all 回归。

不新增核心 ABI，不在 runtime 中加入视觉算子，不把 NG 与执行失败合并。
不承诺毫米标定、旋转尺度匹配、多目标模板定位、轮廓多边形、现场精度，
也不关闭 T22～T27 或 E08 的生产范围。
实际进度与验收证据以 VAL-032 和主进度文档为准。
