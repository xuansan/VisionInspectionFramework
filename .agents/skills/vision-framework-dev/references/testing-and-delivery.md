# 测试与交付

辅助脚本要求Python 3.9及以上，Windows命令推荐使用`python -X utf8`处理中文路径和输出。

开发定位：verify_project.py --scope extension，仅构建外部项目并执行user.<name>.*。
正式交付：默认--scope all，先调用tools/build.cjs windows-all，再构建和验证业务工程。
默认无网络下载；缺少Qt/ORT/native/RustFS等依赖时查看框架环境文档，不能冒充测试通过。
这套脚本首版沿用仓库本地SDK布局，不负责通用依赖安装或发布打包。

- 正常及NG/Unknown结果，启动停止与再次启动。
- 新增设备/输出的拒绝、超时、异常退出，以及其他部分是否仍响应。
- 图像租约/容量票据、子进程退出和过期回执。
- 数据不完整/损坏时的可诊断结果，不只测试返回码为0。
- 基于用户真实输入补业务断言；模板测试不能代替模型精度、真实PLC或现场节拍。

脚本保存命令阶段日志和summary.json。先检查退出码和确实执行的测试数量，再汇报。
构建配置间有重复用例，不把数量相加冒充独立功能数。
超时、依赖缺失或权限失败先定位，不自动删除数据、提升权限或改系统设置来掩盖问题。

最终交付：改动位置/复用模块、运行命令、测试证据、未完成项、部署/许可限制。
Skill格式校验只证明结构正确；独立Agent新会话试用与速度收益要另有记录。
框架API变更后审查compatibility.json列出的差异，修订模板/文档并重跑，才更新指纹。
